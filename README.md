# smocket-site

Landing page for [smocket](https://github.com/electrohyun/smocket) — a Socket.IO
mock library. Built with Next.js (App Router) + TypeScript. Dark-only, single page.

## Develop

```bash
pnpm install
pnpm dev      # http://localhost:3000
```

## Structure

- All copy lives in `content/landing.ts` (single source; do not hardcode strings in JSX).
- One component per section in `app/components/`, in the order defined by the spec.
- See `TODO.md` for pending materials and values.
